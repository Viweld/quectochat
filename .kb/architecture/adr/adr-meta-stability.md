# ADR Meta: Стабильность ADR

**Статус:** Принято  
**Дата:** 2026-07-08

## Контекст

Архитектура прошла финальный аудит; нужна защита от «тихих» переписываний правил.

## Решение

- ADR **стабилен** после принятия; не переписывается из-за частных исключений.
- Изменение архитектуры → новый ADR или обновление с **явной причиной** и датой в начале файла.
- Исключения в коде без ADR — запрещены.

### Checkpoint после PR3

Допустимы корректировки README/ADR **только по фактам** из эталонного `features/auth`, не из теоретических рассуждений.

## Последствия

- Архитектура заморожена; эволюция — через явные ADR.
