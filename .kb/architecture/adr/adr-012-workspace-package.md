# ADR-012: Критерии нового workspace-пакета

**Статус:** Принято  
**Дата:** 2026-07-08

## Контекст

Риск чрезмерной фрагментации (один экран = один пакет).

## Решение

Новый workspace-пакет — **только если**:

- самостоятельная бизнес-фича (bounded context);
- удаляется независимо;
- собственные маршруты, состояние и/или данные;
- **либо** shared-модуль (`shared_*`, `navigation*`, `infrastructure`).

Экраны — внутри `features/<context>/presentation/`, не отдельные пакеты (`auth_login/` ❌).

## Последствия

- Один пакет = bounded context или shared kernel.
- Микромодульность: feature удаляется целиком (кроме `app_di` + `navigation`).
