# ADR-008: Directory on Demand

**Статус:** Принято  
**Дата:** 2026-07-08

## Контекст

Пустые папки в scaffold создают ложное ощущение структуры и усложняют навигацию.

## Решение

Новая папка в `domain/`, `data/` или `presentation/` появляется **только** когда:

- существует минимум **два** связанных класса, которым нужен общий каталог; **или**
- один самостоятельный архитектурный элемент, оправдывающий отдельную папку.

**Запрещено** включать в шаблон/feature scaffold пустые каталоги «на вырост».

При добавлении **новой** папки в `domain/` — обязателен **ADR update**.

## Последствия

- Структура отражает реальный код, а не шаблон.
- Новые каталоги в domain документируются в ADR.
